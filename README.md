# Camp & Beach Booking

Website pemesanan camping dan wisata pantai yang dirancang untuk memudahkan wisatawan mencari destinasi, melihat fasilitas, dan melakukan pemesanan.

## Fitur
- Informasi destinasi wisata
- Pemesanan camping dan pantai
- Informasi fasilitas
- Pengelolaan booking
- Dashboard pengelola

## Teknologi
- HTML
- CSS
- JavaScript

## Project
Project ini dibuat untuk memenuhi tugas mata kuliah Pengembangan dan Pengelolaan Sistem Informasi (PPSI).
